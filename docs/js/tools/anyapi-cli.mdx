## Prerequisites

```bash
npm install @getanyapi/sdk
export ANYAPI_API_KEY=your-anyapi-api-key
```

<Warning>
Running an AnyAPI API charges real USD per call. Check the reported cost before scaling up.
</Warning>

## Basic Search

```bash
praisonai-ts agent run \
  --tools anyapi \
  --prompt "find an Instagram profile"
```

## Filter by Category

```bash
praisonai-ts agent run \
  --tools "anyapi:category=social" \
  --prompt "find the follower count for @nike"
```

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `ANYAPI_API_KEY` | Yes | AnyAPI API key |
| `OPENAI_API_KEY` | Yes | OpenAI API key |
