Agents can return structured data in specific formats - JSON, lists, or custom schemas.


## Quick Start

<Steps>

<Step title="Simple Usage">
```typescript
import { Agent } from 'praisonai';

const agent = new Agent({
  instructions: 'Extract contact information as JSON.',
  llm: 'gpt-4o-mini',
  outputSchema: {
    type: 'object',
    properties: {
      name: { type: 'string' },
      email: { type: 'string' },
      phone: { type: 'string' }
    },
    required: ['name']
  }
});

const result = await agent.start('John Smith, john@example.com, 555-1234');
// {"name":"John Smith","email":"john@example.com","phone":"555-1234"}
```
</Step>

<Step title="With Configuration">

`outputSchema` takes a JSON Schema object. See [Structured Output](/js/structured-output) for the full API.

```typescript
const agent = new Agent({
  instructions: 'Extract product info',
  outputSchema: {
    type: 'object',
    properties: {
      name: { type: 'string' },
      price: { type: 'number' },
      inStock: { type: 'boolean' }
    },
    required: ['name', 'price']
  }
});
```
</Step>

</Steps>

## Schema-Constrained Output

Pass a JSON Schema object to `outputSchema` and the agent returns a JSON string that matches it.

```typescript
import { Agent } from 'praisonai';

const agent = new Agent({
  instructions: 'Summarise the text.',
  llm: 'gpt-4o-mini',
  outputSchema: {
    type: 'object',
    properties: {
      title: { type: 'string' },
      points: { type: 'array', items: { type: 'string' } },
      score: { type: 'number' }
    },
    required: ['title', 'points']
  }
});

const json = await agent.start('Summarise: ...');
const summary = JSON.parse(json);
```

<Info>
`outputSchema` is **OpenAI-only** in v1.7.4. Non-OpenAI providers log a warning and return unstructured text. See [Structured Output](/js/structured-output) for the full API and provider notes.
</Info>

## Best Practices

<AccordionGroup>
  <Accordion title="Use schemas for consistency">
    A JSON Schema ensures the agent returns the same structure every time.
  </Accordion>

  <Accordion title="Keep schemas simple">
    Start with basic types. Deeply nested schemas can confuse some models.
  </Accordion>

  <Accordion title="Mark required fields">
    List the fields you always expect in `required` so they aren't dropped.
  </Accordion>
</AccordionGroup>
