The `package` command manages PraisonAI packages and extensions.

<Info>
**Install requirement:** `praisonai package` requires `pip install praisonai` (the full wrapper). On a standalone `pip install praisonai-code` install every `package` subcommand exits `1` with `package requires the full wrapper. Install the full wrapper: pip install praisonai` — a single-line hint, no Rich traceback ([PR #2854](https://github.com/MervinPraison/PraisonAI/pull/2854)).
</Info>

## Usage

```bash
praisonai package [OPTIONS] COMMAND [ARGS]...
```

## Commands

| Command | Description |
|---------|-------------|
| `install` | Install a package |
| `uninstall` | Uninstall a package |
| `list` | List installed packages |

## Examples

### Install a package

```bash
praisonai package install my-package
```

### List packages

```bash
praisonai package list
```

### Uninstall a package

```bash
praisonai package uninstall my-package
```
