The `research` command enables research and analysis capabilities.

<Info>
**Install requirement:** `praisonai research` requires `pip install praisonai` (the full wrapper). On a standalone `pip install praisonai-code` install every `research` subcommand exits `1` with `research requires the full wrapper. Install the full wrapper: pip install praisonai` — a single-line hint, no Rich traceback ([PR #2854](https://github.com/MervinPraison/PraisonAI/pull/2854)).
</Info>

## Usage

```bash
praisonai research [OPTIONS] [TOPIC]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `TOPIC` | Research topic or question |

## Options

| Option | Short | Description | Default |
|--------|-------|-------------|---------|
| `--model` | `-m` | LLM model to use | `gpt-4o-mini` |
| `--verbose` | `-v` | Verbose output | `false` |
| `--depth` | `-d` | Research depth (shallow, medium, deep) | `medium` |

## Examples

### Research a topic

```bash
praisonai research "Climate change impacts"
```

### Deep research

```bash
praisonai research "AI ethics" --depth deep
```
