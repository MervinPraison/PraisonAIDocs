---
title: "Tools Discover CLI"
description: "CLI commands for discovering tools from packages"
---

```bash
praisonai tools discover
```

<Note>
`praisonai tools discover` now surfaces the `registered` bucket alongside installed packages — including tools contributed by third-party entry points. As of [PR #2642](https://github.com/MervinPraison/PraisonAI/pull/2642), the command consults the full `ToolResolver` source list, so entry-point plugin and `ToolRegistry`-registered tools show up here instead of being hidden. The canonical entry-point group is now `praisonai.tools`; the legacy `praisonaiagents.tools` and `praisonai.tool_sources` groups still surface with a `DeprecationWarning` on first discovery. See [Tools Discover](/cli/tools-discover) for the source bucket reference.
</Note>

```bash
praisonai tools discover --include praisonai_tools.video
```

```bash
praisonai tools discover --include my_custom_tools
```

```bash
praisonai tools discover --entrypoints
```
