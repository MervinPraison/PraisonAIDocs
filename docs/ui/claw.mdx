**PraisonAI 🦅 Dashboard** (`praisonai dashboard`, with `praisonai claw` kept as an alias) connects your AI agents to **Telegram, Discord, Slack**, and more messaging platforms — all from a single command. Install once, launch the dashboard, and add channels from the UI.

<img src="https://raw.githubusercontent.com/MervinPraison/PraisonAI/main/.github/images/ui/claw-desktop-light.webp" alt="praisonai dashboard in light mode with Chat + Canvas as the home view" />

## Quick Start

<Steps>

<Step title="Install">

```bash
pip install "praisonai[dashboard]"
```

`pip install "praisonai[claw]"` is kept as an alias and installs the same packages.

</Step>

<Step title="Set your API key">

```bash
export OPENAI_API_KEY="your-api-key-here"
```

</Step>

<Step title="Launch">

```bash
praisonai dashboard
# Alias: praisonai claw
```

Open **http://localhost:8082** — the dashboard opens in **Chat + Canvas** with the 🦅 welcome greeting and all 16 sidebar pages (including **Connect** for MCP clients).

</Step>

</Steps>

## Connect a Channel (via UI)

The easiest way to add a messaging channel is through the dashboard:

<Steps>

<Step title="Open the Channels page">

In the dashboard sidebar, click **📡 Channels**.

</Step>

<Step title="Click + Add Channel">

Select a platform from the dropdown:

| Platform | Token needed |
|---|---|
| ✈️ **Telegram** | Bot Token (from @BotFather) |
| 🎮 **Discord** | Bot Token (from Developer Portal) |
| 💬 **Slack** | Bot Token + App Token |
| 📱 **WhatsApp** | Access Token + Phone Number ID |
| 🔒 **Signal** | Phone Number + API URL |
| 💼 **Google Chat** | Service Account + Space Name |
| 🟣 **Nostr** | Private Key + Relay URL |

</Step>

<Step title="Paste your token and click Add">

The dashboard shows setup steps for each platform right in the form. Once added, your bot starts automatically — you'll see a **● Connected** status.

</Step>

<Step title="Test the connection">

Click **🔍 Test** on any channel card to verify your bot is responding. You can also **Disable**, **Restart**, or **Delete** channels from the same card.

</Step>

</Steps>

## Get Platform Tokens

### Telegram

1. Open Telegram → search **@BotFather**
2. Send `/newbot` → follow the prompts
3. Copy the **Bot Token**

<Warning>
**Don't share a Telegram token across processes.** Telegram allows only one active `getUpdates` poller per bot token. Don't add a Telegram channel to Claw with a token that's also being polled by `praisonai bot telegram` or a gateway `telegram` channel — the second poller fails fast with `RuntimeError: Another process is already polling this Telegram token`. Give Claw its own token, or stop the other instance first. See [Bot CLI 409 troubleshooting](/cli/bot#409-conflict-bot-stops-replying).
</Warning>

### Discord

1. Go to [discord.com/developers](https://discord.com/developers/applications) → **New Application**
2. Go to **Bot** → **Reset Token** → copy it
3. Enable **Message Content Intent** under Privileged Gateway Intents
4. Go to **OAuth2 → URL Generator** → select `bot` scope → invite to your server

### Slack

1. Go to [api.slack.com/apps](https://api.slack.com/apps) → **Create New App → From Scratch**
2. **OAuth & Permissions** → add scopes: `chat:write`, `app_mentions:read`
3. Enable **Socket Mode** → copy the **App Token** (`xapp-...`)
4. **Install to Workspace** → copy the **Bot Token** (`xoxb-...`)

## CLI Options

```bash
praisonai dashboard                        # Dashboard on port 8082 (alias: praisonai claw)
praisonai dashboard --port 9000            # Custom port
praisonai dashboard --host 127.0.0.1       # Localhost only
praisonai dashboard --app my-dashboard.py  # Custom app file
praisonai dashboard --reload               # Auto-reload on changes
```

<Note>
**Auto-refresh & graceful shutdown:** On launch, `~/.praisonai/claw/app.py` is stamped with `# praisonai-default-app sha256=...`. Untouched copies (including pre-stamp shipped copies) automatically refresh to the latest bundled default when you upgrade; copies you edited are never overwritten (delete your copy to switch back to the bundled default). The launcher invokes `sys.executable -m praisonaiui.cli run` and forwards `SIGTERM` cleanly to stop the child server (10 s fallback to `SIGKILL`).
</Note>

Layout, timeouts, upload limits and data directories are set with [aiui Environment Variables](/features/aiui-environment-variables).

| **Agent Runtime** | Multi-agent orchestration with 100+ tools |
| **Gateway** | API server with SSE streaming |
| **Web Search** | Tavily, Crawl4AI, DuckDuckGo |
| **Session Management** | Per-user conversation isolation |
