Stop a hung or runaway gateway turn cooperatively using the same `InterruptController` primitive the CLI uses for Ctrl-C.

<Note>
The wire-level `message_abort` event and the `InterruptController` primitive shown here are present in the SDK today. The gateway-side **`/stop` chat command**, the **`abort` WebSocket frame**, and the **`gateway.per_turn_timeout`** config key are delivered by [PraisonAI#3472](https://github.com/MervinPraison/PraisonAI/pull/3472); this page documents the verified contract and will be extended with the exact `per_turn_timeout` values and terminal-frame shape once that PR merges.
</Note>

```python
from praisonaiagents import Agent
from praisonaiagents.agent.interrupt import InterruptController

controller = InterruptController()
agent = Agent(name="gateway-agent", instructions="Answer questions.", interrupt_controller=controller)
```

The gateway relays a `message_abort` event to clients when a turn is cancelled, so a custom client can render the turn as "cancelled" instead of hanging or leaking a raw traceback.

## Quick Start

<Steps>
  <Step title="Attach an InterruptController to the agent">
    The controller is the shared primitive that both the CLI and the gateway drive to cancel a turn cooperatively.

    ```python
    from praisonaiagents import Agent
    from praisonaiagents.agent.interrupt import InterruptController

    controller = InterruptController()
    agent = Agent(
        name="gateway-agent",
        instructions="Answer questions.",
        interrupt_controller=controller,
    )
    ```
  </Step>
  <Step title="Request cancellation of the running turn">
    Calling `request()` signals the active turn to stop at the next cooperative checkpoint.

    ```python
    controller.request()
    ```
  </Step>
  <Step title="Render the message_abort event on the client">
    When the gateway cancels a turn it emits a `message_abort` event; treat it as a terminal outcome for that turn.

    ```python
    from praisonaiagents.gateway.protocols import EventType

    if event["type"] == EventType.MESSAGE_ABORT.value:  # "message_abort"
        mark_turn_cancelled(event)
    ```
  </Step>
</Steps>

## The `message_abort` event

`EventType.MESSAGE_ABORT` is defined in `praisonaiagents/gateway/protocols.py` and serialises to the wire string `"message_abort"`.

| Enum member | Wire value | Meaning |
|-------------|-----------|---------|
| `EventType.MESSAGE_ABORT` | `"message_abort"` | The currently-driving turn on the session was cancelled; the client should treat it as terminal. |

<Note>
Because `EventType` is a `str` `Enum`, `EventType.MESSAGE_ABORT == "message_abort"` compares `True`, so clients can match on the raw string without importing the enum.
</Note>

## The shared cancellation primitive

Both the terminal (`praisonai chat` Ctrl-C) and the gateway drive the same `InterruptController`, so cancellation behaves identically across surfaces.

<AccordionGroup>
  <Accordion title="Why cancellation is cooperative">
    `InterruptController.request()` sets a flag the running turn checks at safe points; the turn unwinds cleanly rather than being killed mid-tool-call, which is why the client receives a typed `message_abort` frame instead of a raw traceback.
  </Accordion>
  <Accordion title="One controller per turn surface">
    A single `InterruptController` instance is shared by the agent and whatever surface cancels it — the CLI Ctrl-C handler, or (per PR #3472) the gateway's `/stop` command, `abort` WS frame, and `per_turn_timeout` expiry.
  </Accordion>
</AccordionGroup>
