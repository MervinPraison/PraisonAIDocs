Deprecated video model IDs are retired or being retired — swap them for the current IDs below. Most fixes are a one-line `llm=` change.

```mermaid
graph LR
    Old[🕰️ Old model string] --> Agent[🎬 VideoAgent llm=...]
    Agent --> New[✅ Current model string]

    classDef old fill:#8B0000,stroke:#7C90A0,color:#fff
    classDef agent fill:#189AB4,stroke:#7C90A0,color:#fff
    classDef new fill:#10B981,stroke:#7C90A0,color:#fff

    class Old old
    class Agent agent
    class New new
```

## Quick Start

```python
from praisonaiagents import VideoAgent

# Before (deprecated)
agent = VideoAgent(llm="gemini/veo-3.0-generate-preview")

# After
agent = VideoAgent(llm="gemini/veo-3.1-generate-preview")
video = agent.start("A sunset timelapse", output="sunset.mp4")
```

## Migration table

| Deprecated string | Replacement | Why | Reference |
|-------------------|-------------|-----|-----------|
| `gemini/veo-3.0-generate-preview` | `gemini/veo-3.1-generate-preview` | Gemini API shutdown 30 Jun 2026 | [Gemini](/video/gemini#deprecated) |
| `gemini/veo-3.0-fast-generate-preview` | `gemini/veo-3.1-fast-generate-preview` | Gemini API shutdown 30 Jun 2026 | [Gemini](/video/gemini#deprecated) |
| `gemini/veo-2.0-generate-001` | `gemini/veo-3.1-generate-preview` | Gemini API shutdown 30 Jun 2026 | [Gemini](/video/gemini#deprecated) |
| `vertex_ai/veo-3.0-generate-preview` | `vertex_ai/veo-3.1-generate-001` | GA Veo 3.1 is the recommended default | [Vertex](/video/vertex#deprecated) |
| `vertex_ai/veo-3.0-fast-generate-001` | `vertex_ai/veo-3.1-fast-generate-001` | Veo 3.1 Fast replaces Veo 3.0 Fast | [Vertex](/video/vertex#deprecated) |
| `vertex_ai/veo-2.0-generate-001` | `vertex_ai/veo-3.1-generate-001` | Veo 2.0 is retired | [Vertex](/video/vertex#deprecated) |
| `runway/gen-3` (old recipe prompt text — never a working `llm=` ID) | `openai/sora-2` for text-only prompts, or `runwayml/gen4_turbo` with an image | `runwayml/gen4_turbo` needs an `input_reference` image | [RunwayML](/video/runwayml) |
| `runway-gen3` (old MCP short alias) | `openai/sora-2` | Current MCP default | [MCP](/mcp/extended-capabilities) |

<Warning>
`runwayml/gen4_turbo` is **image-to-video** — a prompt-only recipe that used `runway/gen-3` must switch to `openai/sora-2`, or add an `input_reference` image.
</Warning>

<Note>
The MCP tool `praisonai.videos.generate` now defaults to `openai/sora-2`. Omit `model`, or pass a full ID from the table above — the old `runway-gen3` alias is no longer meaningful.
</Note>
