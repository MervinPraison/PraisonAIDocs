PraisonAI runs AI agents on your own computers, even fully offline, so private data never has to leave the building. It is built for highly regulated teams, and free and open source for everyone.

**Private AI that earns trust one task at a time.**

```python
from praisonaiagents import Agent

agent = Agent(instructions="You are a helpful assistant")
agent.start("Write a haiku about AI")
```

## What is PraisonAI?

PraisonAI is an open-source Python framework for building AI agents. It is still a general-purpose framework: build any kind of agent, with any model, in the cloud or on your own computers. Our company focus is private AI for regulated teams, and this framework is the foundation for that work.

## When to Use What

```mermaid
graph LR
    Q{What do you need?}
    
    Q -->|"One agent, one task"| A["🤖 Agent"]
    Q -->|"Multiple agents collaborate"| B["👥 AgentTeam"]

    Q -->|"Production API"| D["⚡ AgentOS"]
    
    classDef question fill:#F59E0B,stroke:#7C90A0,color:#fff
    classDef agent fill:#189AB4,stroke:#7C90A0,color:#fff
    classDef prod fill:#8B0000,stroke:#7C90A0,color:#fff
    
    class Q question
    class A,B,C agent
    class D prod
```

| Scenario | Use This |
|----------|----------|
| Chat with one AI | `Agent` |
| Research → Analyze → Write | `AgentTeam` or `AgentFlow` |
| Route to specialists | `AgentFlow` + `route()` |
| Parallel processing | `AgentFlow` + `parallel()` |
| Production API | `AgentOS` |

## How It Works

An Agent receives your instructions, calls the LLM, and returns a result — teams and flows chain multiple agents on top of that.

```mermaid
sequenceDiagram
    participant User
    participant Agent
    participant LLM

    User->>Agent: Agent(instructions="…").start("…")
    Agent->>LLM: Send prompt to the selected model
    LLM-->>Agent: Model response
    Agent-->>User: Final answer
```

## Best Practices

<AccordionGroup>
<Accordion title="Pick the right building block">
Use `Agent` for one task, `AgentTeam` when agents collaborate, and `AgentFlow` for step-based pipelines with routing, parallel, or loop patterns.
</Accordion>

<Accordion title="Keep the first example tiny">
Start with `Agent(instructions="…").start("…")`. Add `name`, `role`, `tools`, and `Task` only as your needs grow.
</Accordion>

<Accordion title="Set provider keys in the environment">
Export `OPENAI_API_KEY` (or another provider's key) in your shell. PraisonAI auto-selects a matching default model.
</Accordion>

<Accordion title="Move to AgentOS for production">
Wrap agents in `AgentOS` when you need an API, webhooks, or a scheduler for production deployment.
</Accordion>
</AccordionGroup>
