`ImageAgent()` works without `llm=`. It defaults to `dall-e-3` for `generate()` and `dall-e-2` for `edit()` and `variation()`. Pass `llm=` when you want a different image model (e.g. `openai/gpt-image-1`).

## Generate Image

<Tabs>
  <Tab title="Basic">
```python
from praisonaiagents import ImageAgent

agent = ImageAgent()
result = agent.generate("A sunset over mountains")
print(result.data[0].url)
```
  </Tab>
  <Tab title="Advanced">
```python
from praisonaiagents import ImageAgent

agent = ImageAgent(llm="openai/dall-e-3", style="vivid")
result = agent.generate("A futuristic city", size="1792x1024", quality="hd")
print(result.data[0].url)
```

`style` is forwarded only for `dall-e-3`. For `dall-e-2` or `gpt-image-1`, `ImageAgent` drops it automatically — no model-specific code needed.
  </Tab>
</Tabs>

## Edit Image

<Tabs>
  <Tab title="Basic">
```python
from praisonaiagents import ImageAgent

# Defaults to dall-e-2; llm= shown for clarity
agent = ImageAgent(llm="openai/dall-e-2")
result = agent.edit("photo.png", "Add a rainbow")
print(result.data[0].url)
```
  </Tab>
  <Tab title="Advanced">
```python
from praisonaiagents import ImageAgent

agent = ImageAgent(llm="openai/dall-e-2")
result = agent.edit("photo.png", "Add sunset", mask="mask.png", size="1024x1024")
print(result.data[0].url)
```
  </Tab>
</Tabs>

## Image Variations

```python
from praisonaiagents import ImageAgent

# Defaults to dall-e-2; llm= shown for clarity
agent = ImageAgent(llm="openai/dall-e-2")
variations = agent.variation("original.png", n=3)
for img in variations.data:
    print(img.url)
```
