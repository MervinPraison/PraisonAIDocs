## Usage

```python
sink = ListSink()
    emitter = TraceEmitter(sink=sink)
    
    emitter.agent_start("researcher")
    emitter.tool_start("search", {"query": "AI"})
    emitter.tool_end("search", duration_ms=100, status="ok")
    emitter.agent_end("researcher", duration_ms=500)
```
