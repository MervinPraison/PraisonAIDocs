Emit LLM response event.

## Signature

```python
def llm_response(agent_name: str, response_tokens: int, duration_ms: float, finish_reason: Optional[str], response_content: Optional[str], prompt_tokens: int, completion_tokens: int, cost_usd: float) -> None
```

## Parameters

<ParamField query="agent_name" type="str" required={true}>
  Name of the agent receiving the response
</ParamField>

<ParamField query="response_tokens" type="int" required={false} default="0">
  Number of tokens in response (deprecated, use completion_tokens)
</ParamField>

<ParamField query="duration_ms" type="float" required={false} default="0.0">
  Response time in milliseconds
</ParamField>

<ParamField query="finish_reason" type="Optional[str]" required={false}>
  Reason for completion (stop, length, etc.)
</ParamField>

<ParamField query="response_content" type="Optional[str]" required={false}>
  Optional response content for context replay
</ParamField>

<ParamField query="prompt_tokens" type="int" required={false} default="0">
  Number of tokens in the prompt/request
</ParamField>

<ParamField query="completion_tokens" type="int" required={false} default="0">
  Number of tokens in the completion/response
</ParamField>

<ParamField query="cost_usd" type="float" required={false} default="0.0">
  Estimated cost in USD for this LLM call
</ParamField>

- `time.time`
