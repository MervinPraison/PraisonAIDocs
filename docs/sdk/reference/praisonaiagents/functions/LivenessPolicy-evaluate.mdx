# evaluate

<div className="flex items-center gap-2">
  <Badge color="purple">Method</Badge>
</div>

> This is a method of the [**LivenessPolicy**](../classes/LivenessPolicy) class in the [**protocols**](../modules/protocols) module.

Return :attr:`LivenessDecision.REAP` iff the connection is stale.

## Signature

```python
def evaluate(last_activity: float, now: float) -> LivenessDecision
```

## Parameters

<ParamField query="last_activity" type="float" required={true}>
  The connection's last-activity timestamp (same clock as ``now`` — the wrapper uses a monotonic clock).
</ParamField>

<ParamField query="now" type="float" required={true}>
  The current timestamp.
</ParamField>

### Returns

<ResponseField name="Returns" type="LivenessDecision">
  attr:`LivenessDecision.KEEP` while reaping is disabled or the
    connection is within its liveness window; otherwise
    :attr:`LivenessDecision.REAP`.
</ResponseField>
