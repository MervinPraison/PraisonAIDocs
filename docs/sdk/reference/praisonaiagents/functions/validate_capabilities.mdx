Validate that a runtime supports all required capabilities.

## Signature

```python
def validate_capabilities(runtime_matrix: RuntimeCapabilityMatrix, required_capabilities: Union[Set[RuntimeCapability], RuntimeCapabilityMatrix], runtime_name: str) -> bool
```

## Parameters

<ParamField query="runtime_matrix" type="RuntimeCapabilityMatrix" required={true}>
  Capability matrix of the runtime
</ParamField>

<ParamField query="required_capabilities" type="Union" required={true}>
  Required capabilities (set or matrix)
</ParamField>

<ParamField query="runtime_name" type="str" required={false} default="'unknown'">
  Name of runtime for error messages
</ParamField>

### Returns

<ResponseField name="Returns" type="bool">
  True if validation passes
</ResponseField>

### Exceptions

<AccordionGroup>
  <Accordion title="CapabilityValidationError">
    If validation fails
  </Accordion>
</AccordionGroup>
