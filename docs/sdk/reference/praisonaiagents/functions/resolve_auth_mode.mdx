# resolve_auth_mode

<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>
</div>

> This function is defined in the [**protocols**](../modules/protocols) module.

Resolve authentication mode based on bind host and explicit configuration.

## Signature

```python
def resolve_auth_mode(bind_host: str, configured: Optional[AuthMode]) -> AuthMode
```

## Parameters

<ParamField query="bind_host" type="str" required={true}>
  Host/IP that the service is bound to
</ParamField>

<ParamField query="configured" type="Optional[AuthMode]" required={false}>
  Explicitly configured auth mode (takes precedence)
</ParamField>

### Returns

<ResponseField name="Returns" type="AuthMode">
  The resolved authentication mode
</ResponseField>

## Usage

```python
>>> resolve_auth_mode("127.0.0.1")
    'local'
    >>> resolve_auth_mode("0.0.0.0")  
    'token'
    >>> resolve_auth_mode("127.0.0.1", "token")
    'token'
```
