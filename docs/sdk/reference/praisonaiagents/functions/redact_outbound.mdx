# redact_outbound

<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>
</div>

> This function is defined in the [**secrets**](../modules/secrets) module.

Scrub secrets from text on its way to a chat user (safe-by-default). Combines the registered-value registry (`redact_secrets`) with a credential-shape regex so an unregistered token surfaced in a tool result is still masked. Never raises — a scrubber error returns the registered-value result rather than blocking delivery.

## Signature

```python
def redact_outbound(text: str) -> str
```

## Parameters

<ParamField query="text" type="str" required={true}>
  Text on its way to a chat user. `None`, `""`, and non-string input are returned unchanged.
</ParamField>

### Returns

<ResponseField name="Returns" type="str">
  The text with every registered secret value and credential-shaped token replaced by `[REDACTED]`.
</ResponseField>
