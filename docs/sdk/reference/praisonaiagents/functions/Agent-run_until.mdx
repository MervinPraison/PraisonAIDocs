# run_until

<div className="flex items-center gap-2">
  <Badge color="purple">Method</Badge>
</div>

> This is a method of the [**Agent**](../classes/Agent) class in the [**agent**](../modules/agent) module.

Run agent iteratively until output meets quality criteria.

This method implements the "Ralph Loop" pattern: run agent → judge output
→ improve based on feedback → repeat until threshold met.

When ``goal`` is provided, delegates to the tool-using goal loop
(:meth:`run_goal`) so the acceptance-criteria completion judge gates a
real tool-iteration loop (rather than re-generating a whole answer).

## Signature

```python
def run_until(prompt: str, criteria: str, threshold: float, max_iterations: int, mode: str, on_iteration: Optional[Callable[[Any], None]], verbose: bool, goal: Optional[str], goal_criteria: Optional[Any], judge_model: Optional[str]) -> 'EvaluationLoopResult'
```

## Parameters

<ParamField query="prompt" type="str" required={true}>
  The prompt to send to the agent
</ParamField>

<ParamField query="criteria" type="str" required={false} default="''">
  Evaluation criteria for the Judge (e.g., "Response is thorough")
</ParamField>

<ParamField query="threshold" type="float" required={false} default="8.0">
  Score threshold for success (default: 8.0, scale 1-10)
</ParamField>

<ParamField query="max_iterations" type="int" required={false} default="5">
  Maximum iterations before stopping (default: 5)
</ParamField>

<ParamField query="mode" type="str" required={false} default="'optimize'">
  "optimize" (stop on success) or "review" (run all iterations)
</ParamField>

<ParamField query="on_iteration" type="Optional" required={false}>
  Optional callback called after each iteration
</ParamField>

<ParamField query="verbose" type="bool" required={false} default="False">
  Enable verbose logging
</ParamField>

<ParamField query="goal" type="Optional[str]" required={false}>
  Optional goal text — enables the tool-using goal loop
</ParamField>

<ParamField query="goal_criteria" type="Optional" required={false}>
  Optional structured GoalCriteria for the goal loop
</ParamField>

<ParamField query="judge_model" type="Optional[str]" required={false}>
  Optional independent judge model for the goal loop
</ParamField>

### Returns

<ResponseField name="Returns" type="'EvaluationLoopResult'">
  when ``goal`` is provided this delegates to the tool-using
    goal loop and returns an
    :class:`~praisonaiagents.agent.autonomy.AutonomyResult` instead
    (``success``/``output``/``completion_reason``), which is a
    different shape from the default ``EvaluationLoopResult``.
</ResponseField>

## Usage

```python
agent = Agent(name="analyzer", instructions="Analyze systems")
    result = agent.run_until(
        "Analyze the auth flow",
        criteria="Analysis is thorough and actionable",
        threshold=8.0,
    )
    print(result.final_score)  # 8.5
    print(result.success)      # True
```
