# get_cache_dir

<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>
</div>

> This function is defined in the [**paths**](../modules/paths) module.

Get cache directory (disposable data).

Under a single-root install this is ``&lt;root&gt;/cache``; on a fresh install it
resolves to ``$XDG_CACHE_HOME/praisonai`` (else ``~/.cache/praisonai``).
