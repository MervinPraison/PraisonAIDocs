# ensure_run_lock

<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>
</div>

> This function is defined in the [**_run_lock**](../modules/_run_lock) module.

Lazily mint `obj._run_lock` under a shared module guard.

`getattr(obj, "_run_lock", None)` works for both the dataclass-field case
(Workflow) and the plain-attribute case (AgentTeam), so the behaviour is
identical to the per-module implementations it replaces.

## Signature

```python
def ensure_run_lock(obj) -> Any
```

## Parameters

<ParamField query="obj" type="Any" required={true}>
  The orchestration instance (AgentTeam or Workflow) whose per-instance `_run_lock` should be returned, creating it on first access.
</ParamField>

### Returns

<ResponseField name="Returns" type="Any">
  The instance's `_run_lock` — the same object for every caller under a concurrent first-access race.
</ResponseField>


## Uses

- `getattr`
- `threading.Lock`
