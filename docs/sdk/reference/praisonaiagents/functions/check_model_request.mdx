# check_model_request

<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>
</div>

> This function is defined in the [**guard**](../modules/guard) module.

Raise :class:`ModelRequestBlocked` if real model requests are blocked.

Call this immediately before handing a request to a provider. When requests
are allowed (the default) it is a single global read.

## Signature

```python
def check_model_request(model: Optional[str], provider: Optional[str]) -> None
```

## Parameters

<ParamField query="model" type="Optional[str]" required={false}>
  Model id the request names, used in the error message.
</ParamField>

<ParamField query="provider" type="Optional[str]" required={false}>
  Short label for the request path being guarded, e.g. ``"litellm.completion"`` or ``"openai.chat.completions"``.
</ParamField>

### Exceptions

<AccordionGroup>
  <Accordion title="ModelRequestBlocked">
    If requests are currently blocked.
  </Accordion>
</AccordionGroup>
