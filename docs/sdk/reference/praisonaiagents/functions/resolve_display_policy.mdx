# resolve_display_policy

<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>
</div>

> This function is defined in the [**config**](../modules/config) module.

Resolve the effective :class:`DisplayPolicy` for a platform.

Precedence (highest first):
    1. explicit ``display.platforms.&lt;platform&gt;.&lt;setting&gt;``
    2. ``display.&lt;setting&gt;`` global default
    3. platform-tier default (edit / work / noedit / batch)
    4. built-in :class:`DisplayPolicy` default

## Signature

```python
def resolve_display_policy(platform: str, config: Optional[Dict[str, Any]]) -> DisplayPolicy
```

## Parameters

<ParamField query="platform" type="str" required={true}>
  Platform name, e.g. ``"telegram"``.
</ParamField>

<ParamField query="config" type="Optional" required={true}>
  A ``display`` config dict (the value of the ``display:`` block), or a full config dict containing a ``display`` key. ``None`` is treated as empty.
</ParamField>

### Returns

<ResponseField name="Returns" type="DisplayPolicy">
  class:`DisplayPolicy`.
</ResponseField>
