# enable

<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>
</div>

> This function is defined in the [**plugins**](../modules/plugins) module.

Enable the plugin system.

Discovers and enables plugins from default directories.
This is the main entry point for using plugins.

## Signature

```python
def enable(plugins: list, options_by_name: dict) -> None
```

## Parameters

<ParamField query="plugins" type="list" required={false}>
  Optional list of plugin names to enable. If None, enables all discovered plugins.
</ParamField>

<ParamField query="options_by_name" type="dict" required={false}>
  Optional ``&#123;plugin_name: options_dict&#125;`` mapping of per-plugin options (e.g. from ``.praisonai/config.yaml``). Each enabled plugin receives its own options via ``on_config``.
</ParamField>

## Usage

```python
# Enable all discovered plugins
    from praisonaiagents import plugins
    plugins.enable()

    # Enable specific plugins only
    plugins.enable(["logging", "metrics"])

    # Enable with per-plugin options
    plugins.enable(["pii_guardrail"], {"pii_guardrail": {"redact": ["email"]}})
```

## Notes

- Tools and guardrails work WITHOUT calling enable()
    - Only background plugins (hooks, metrics, logging) need enable()
    - Can also be enabled via PRAISONAI_PLUGINS env var
    - Can also be enabled via .praisonai/config.yaml (unified) or config.toml
