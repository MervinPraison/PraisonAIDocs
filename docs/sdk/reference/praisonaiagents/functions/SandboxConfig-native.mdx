# native

<div className="flex items-center gap-2">
  <Badge color="purple">Method</Badge>
</div>

> This is a method of the [**SandboxConfig**](../classes/SandboxConfig) class in the [**config**](../modules/config) module.

Create an OS-native sandbox configuration.

`SandboxConfig.native()` maps to the `sandlock` backend (Linux Landlock + seccomp) and requires the optional `praisonai-sandbox[sandlock]` wheel. On macOS — and on any Linux host without that wheel — this raises `ImportError`; it does **not** provide macOS Seatbelt.

<Warning>
macOS Seatbelt (`sandbox-exec`) and Linux `bwrap` containment live in the `praisonai code` CLI, not in `SandboxConfig.native()`. Reach them by running the coding agent with [`PRAISON_SHELL=sandboxed`](/features/os-sandbox), which drives the OS primitives directly and refuses to run unless enforcement is proven.
</Warning>
