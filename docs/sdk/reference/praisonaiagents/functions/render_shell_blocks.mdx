<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>

> This function is defined in the [**shell_render**](../modules/shell_render) module.

Render ``!`cmd` `` and ```` ```! `` blocks inside a skill body.

## Signature

```python
def render_shell_blocks(body: str, enabled: bool, shell: str, timeout: int, cwd: Optional[str]) -> str
```

## Parameters

<ParamField query="body" type="str" required={true}>
  SKILL.md body (post-substitution).
</ParamField>

<ParamField query="enabled" type="bool" required={false} default="False">
  Master switch. When False, every block is replaced with ``[shell execution disabled]``. Defaults to False.
</ParamField>

<ParamField query="shell" type="str" required={false} default="'bash'">
  ``bash`` (default) or ``powershell``.
</ParamField>

<ParamField query="timeout" type="int" required={false} default="15">
  Per-command timeout in seconds.
</ParamField>

<ParamField query="cwd" type="Optional[str]" required={false}>
  Working directory for commands (typically the skill dir).
</ParamField>

### Returns

<ResponseField name="Returns" type="str">
  Body with shell placeholders resolved.
</ResponseField>
