# cli-backend

<Badge color="green">TypeScript AI Agent</Badge>

* CLI backend module for the PraisonAI TypeScript SDK.
* Python parity: praisonaiagents/cli_backend (protocols.py).
* Protocol-driven contracts for using an external CLI agent as an Agent
backend, plus bridges to `src/cli/features/external-agents.ts`.

## Import

```typescript
import { cli-backend } from 'praisonai';
```
