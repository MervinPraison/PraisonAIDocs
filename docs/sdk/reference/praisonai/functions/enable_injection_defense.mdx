# enable_injection_defense

<div className="flex items-center gap-2">
  <Badge color="teal">Function</Badge>
</div>

> This function is defined in the [**security**](../modules/security) module.

Enable prompt injection defense globally for all agents.

Registers hooks on BEFORE_TOOL and BEFORE_AGENT events that scan
inputs through a 6-check pipeline and block critical threats.

## Signature

```python
def enable_injection_defense(extra_patterns: Optional[List[str]], block_threshold: Optional[int], trusted_sources: Optional[List[str]]) -> str
```

## Parameters

<ParamField query="extra_patterns" type="Optional" required={false}>
  Additional regex patterns to detect (appended to defaults).
</ParamField>

<ParamField query="block_threshold" type="Optional[int]" required={false}>
  Override the threat level that triggers blocking. 3 = CRITICAL, 2 = HIGH (default), 1 = MEDIUM.
</ParamField>

<ParamField query="trusted_sources" type="Optional" required={false}>
  Source names that bypass blocking (in addition to defaults).
</ParamField>

### Returns

<ResponseField name="Returns" type="str">
  &#123;"before_tool": str, "before_agent": str&#125;
</ResponseField>

>>> from praisonai.security import enable_injection_defense
    >>> enable_injection_defense()
