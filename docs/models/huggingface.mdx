## Quick Start

<Steps>
<Step title="Install">
```bash
pip install "praisonaiagents[llm]"
```
</Step>

<Step title="Set credentials">
```bash
export HUGGINGFACE_API_KEY=your-hf-token
```
</Step>

<Step title="Run an agent">
```python
from praisonaiagents import Agent

agent = Agent(
    instructions="You are a helpful assistant",
    model="huggingface/meta-llama/Llama-3.1-8B-Instruct",
)

agent.start("Hello!")
```
</Step>
</Steps>

## How it works

The `huggingface/` prefix tells PraisonAI to route the request through litellm to Hugging Face, which reads `HUGGINGFACE_API_KEY` from your environment. See [Provider Auto-Detection](/models#provider-auto-detection-no-config-first-run) for how model strings are resolved.

```mermaid

    Agent->>litellm: model="huggingface/..."
    litellm->>Provider: Request with your credentials
    Provider-->>Agent: Model reply
    Agent-->>User: Response
```

## Common Patterns

### Pick a different model

Keep the `huggingface/` prefix and swap the rest for any model your Hugging Face account offers.

```python
from praisonaiagents import Agent

agent = Agent(
    instructions="You are a helpful assistant",
    model="huggingface/meta-llama/Llama-3.1-8B-Instruct",
)
```

### Tune the response with a config dict

Pass a dict to set temperature, token limits, or other options.

```python
from praisonaiagents import Agent

agent = Agent(
    instructions="You write short, friendly answers",
    model={
        "model": "huggingface/meta-llama/Llama-3.1-8B-Instruct",
        "temperature": 0.3,
        "max_tokens": 500,
    },
)

agent.start("Give me three tips for better sleep.")
```

## Best Practices

<AccordionGroup>
<Accordion title="Prefer the shortest form">
Start with `model="huggingface/meta-llama/Llama-3.1-8B-Instruct"` and nothing else. Add a config dict only when you need to tune temperature or limits.
</Accordion>

<Accordion title="Set the provider key once via env">
Export `HUGGINGFACE_API_KEY` in your shell or `.env` file. Keep keys out of your code.
</Accordion>

<Accordion title="Keep model= canonical">
Always use `model=`. The older `llm=` name still works but prints a deprecation warning. See [Model Parameter](/features/model-parameter).
</Accordion>
</AccordionGroup>
