## Models

Heabsy is an OpenAI-compatible inference API for open models. Models in the EEA tier run on dedicated GPUs in EEA data centres with zero data retention; models routed through third parties are labelled as such in the catalog.

Pass a bare model id with `base_url="https://api.heabsy.com/v1"` — PraisonAI routes it as `openai/<model>`. See [OpenAI-Compatible Endpoints](/models/openai-compatible).

**Recommended Models:**
- **Qwen3.8 27B**: `qwen38` (262,144-token context, up to 32,768 output tokens, vision input, tool calling, structured output)

<Note>
Heabsy does not serve `/v1/embeddings`. Configure embeddings with a separate provider — see [Embeddings](/capabilities/embeddings).
</Note>

## Python

```python
# export HEABSY_API_KEY=your-api-key
import os
from praisonaiagents import Agent

agent = Agent(
    instructions="You are a helpful assistant",
    llm="qwen38",
    base_url="https://api.heabsy.com/v1",
    api_key=os.environ["HEABSY_API_KEY"]
)
agent.start("Explain neural networks")
```

### With Tools

```python
# export HEABSY_API_KEY=your-api-key
import os
from praisonaiagents import Agent

def search_web(query: str) -> str:
    """Search the web for information."""
    return f"Search results for: {query}"

agent = Agent(
    instructions="You are a research assistant",
    llm="qwen38",
    base_url="https://api.heabsy.com/v1",
    api_key=os.environ["HEABSY_API_KEY"],
    tools=[search_web]
)
agent.start("What's happening in AI today?")
```

### Multi-Agent

```python
# export HEABSY_API_KEY=your-api-key
import os
from praisonaiagents import Agent, Task, AgentTeam

researcher = Agent(
    instructions="You research topics thoroughly",
    llm="qwen38",
    base_url="https://api.heabsy.com/v1",
    api_key=os.environ["HEABSY_API_KEY"]
)
writer = Agent(
    instructions="You write clear summaries",
    llm="qwen38",
    base_url="https://api.heabsy.com/v1",
    api_key=os.environ["HEABSY_API_KEY"]
)

task1 = Task(description="Research quantum computing", agent=researcher)
task2 = Task(description="Summarize findings", agent=writer)

agents = AgentTeam(agents=[researcher, writer], tasks=[task1, task2])
agents.start()
```

## CLI

```bash
export HEABSY_API_KEY=your-api-key
export OPENAI_API_KEY="${HEABSY_API_KEY:?Set HEABSY_API_KEY in your shell}"
export OPENAI_BASE_URL=https://api.heabsy.com/v1

# Basic prompt
python -m praisonai "Explain AI" --llm openai/qwen38

# Run agents.yaml
python -m praisonai
```

## YAML

```yaml
# Uses OPENAI_API_KEY and OPENAI_BASE_URL from the CLI section
framework: praisonai
topic: Research AI developments
agents:
  researcher:
    role: AI Researcher
    goal: Find latest AI developments
    instructions: You are an expert AI researcher
    llm:
      model: openai/qwen38
    tasks:
      research_task:
        description: Research the latest developments in AI
        expected_output: Comprehensive AI research report

  writer:
    role: Technical Writer
    goal: Create clear documentation
    instructions: You write clear technical content
    llm:
      model: openai/qwen38
    tasks:
      write_task:
        description: Write a summary of the research
        expected_output: Well-written technical summary
```
