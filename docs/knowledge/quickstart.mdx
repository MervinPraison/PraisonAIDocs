# Knowledge Quick Start

Give your agent access to documents and get answers with citations.

## Installation

```bash
pip install "praisonaiagents[knowledge]"
```

## 1. Simplest Usage (Default)

```python
from praisonaiagents import Agent

agent = Agent(
    name="Research Assistant",
    knowledge=["research.pdf"]  # Just pass files
)

response = agent.start("What are the key findings?")
```

## 2. Multiple Sources (Array)

```python
from praisonaiagents import Agent

agent = Agent(
    name="Research Assistant",
    knowledge=[
        "paper.pdf",
        "notes.txt", 
        "docs/",           # Entire directory
    ]
)

response = agent.start("Summarize all documents")
```

<Note>
URL sources in `Agent(knowledge=[...])` are **not yet supported** in the core SDK. Since PraisonAI PR [#4004](https://github.com/MervinPraison/PraisonAI/pull/4004) any `http://` or `https://` entry is logged with a warning and skipped instead of being silently dropped. The warning logs only `scheme://hostname`, so signed-URL tokens and credentials never leak into your logs. Fetch the page's content yourself and pass the text, or download it and pass the local file path, if you need it indexed.
</Note>

## 3. Custom Configuration (Dict)

```python
from praisonaiagents import Agent

agent = Agent(
    name="Research Assistant",
    knowledge={
        "sources": ["research.pdf", "data/"],
        "chunker": {
            "type": "semantic",      # Better topic boundaries
            "chunk_size": 512
        },
        "vector_store": {
            "provider": "chroma",
            "config": {"collection_name": "my_research"}
        }
    }
)

response = agent.start("What methodology was used?")
```

## 4. With Retrieval Options

```python
from praisonaiagents import Agent

agent = Agent(
    name="Research Assistant",
    knowledge={
        "sources": ["research.pdf"],
        "retrieval_k": 5,            # Number of chunks
        "rerank": True               # Better relevance
    }
)

result = agent.query("What are the conclusions?")
print(result.answer)
print(result.citations)
```

## 5. Shared Knowledge (Instance)

```python
from praisonaiagents import Agent, Knowledge

# Create shared knowledge base
kb = Knowledge(config={
    "vector_store": {"provider": "chroma"}
})
kb.add("company_docs/")

# Multiple agents share same knowledge
analyst = Agent(name="Analyst", knowledge=kb)
writer = Agent(name="Writer", knowledge=kb)
```

## Supported File Types

`Agent(knowledge=[...])` accepts local files, directories, and raw text.

| Input | Accepted by `Agent(knowledge=[...])` |
|-------|--------------------------------------|
| Documents (PDF, DOC, DOCX, TXT, MD, RTF) | Yes |
| Data (CSV, JSON, XML, Excel) | Yes |
| Directories | Yes — every supported file inside |
| Raw text strings | Yes — stored directly |
| Local HTML files (`.html`, `.htm`) | Yes |
| Remote URLs (`http://`, `https://`) | No — warned and skipped; fetch first |

<Note>
URL ingestion is not yet implemented — this applies to both
`Agent(knowledge=[url])` and the standalone `Knowledge.add(url)`, which raises
`NotImplementedError`. Fetch the content and pass it as text or a local file.
</Note>
